# UCI Heart Disease, four hospitals

Processed tables (14 attributes) of the UCI Heart Disease data, converted to
CSV from the R package `ucidata` (github.com/coatless/ucidata), which bundles
the original files `processed.{cleveland,hungarian,switzerland,va}.data` from
https://archive.ics.uci.edu/dataset/45/heart+disease (license CC BY 4.0).

| File | Hospital | Patients |
|---|---|---|
| cleveland.csv | Cleveland Clinic Foundation | 303 |
| hungary.csv | Hungarian Institute of Cardiology, Budapest | 294 |
| switzerland.csv | University Hospitals of Zurich and Basel | 123 |
| va_long_beach.csv | V.A. Medical Center, Long Beach | 200 |

The donors ask that publications name the principal investigators: Andras
Janosi, M.D. (Hungarian Institute of Cardiology, Budapest); William
Steinbrunn, M.D. (University Hospital, Zurich); Matthias Pfisterer, M.D.
(University Hospital, Basel); Robert Detrano, M.D., Ph.D. (V.A. Medical
Center, Long Beach, and Cleveland Clinic Foundation).

`num` is the angiographic diagnosis (0: no disease; 1-4: disease). Missing
values are empty cells.
